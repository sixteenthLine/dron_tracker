## Local Export Evidence

The local export's `README.roboflow.txt` identifies **Heridal v2 yolo_non_412**,
an export dated October 17, 2022, containing 1,546 images with COCO annotations.
Its `README.dataset.txt` declares **CC BY 4.0** and supplies this dataset page:
<https://universe.roboflow.com/object-detection/heridal-t428z>.

The COCO JSON also assigns the CC BY 4.0 license record to all images. The
[current public page for the same project ID](https://universe.roboflow.com/new-workspace-qsuag/heridal-t428z)
declares that license. These facts do not verify annotation quality, the exact
historical training data, or completed training. Two visually inspected,
full-frame examples serve as offline still-image demos. New offline training and
validation now use the audited positive-image subset; video/tracking demos still
use synthetic media, not this export.

Original HERIDAL data is credited separately from its Roboflow export; upstream
distribution cites CC BY 3.0. See [media provenance](../assets/SAMPLE_SOURCE.md)
for both licensing declarations and selected source filenames/hashes.

## New Training Split

The October 22 preparation pass verified all 1,546 image files and 2,892 boxes,
including dimensions, bounds, and SHA-256 hashes. It found no missing images,
invalid boxes, or exact duplicate images. Annotation completeness and near-duplicate
scenes remain unverified. The 561 unannotated images are excluded, not assumed
verified negatives. Splits are grouped by filename prefix before generating crops:

| Split | Images | Boxes | Filename groups |
|---|---|---|---|
| Train | 535 | 1,152 | BLA, BRA, BRS, CAP, GOR, JAS, MED, SB, TRS |
| Validation | 167 | 267 | BRK, RAK |
| Test | 283 | 1,473 | VRD, ZRI |

Prefixes are only scene proxies, not verified independent locations. The two
published examples belong to test groups. Test metrics have not been evaluated;
small validation subsets are not full-dataset benchmarks. Positive-only metrics
cannot establish background false-positive rates. See [training](TRAINING.md) and
[execution evidence](validation/TRAINING_VALIDATION.md).

## Interpreting The Old Audit

The original audit correctly reported that the referenced dataset was missing
at audit time. That historical finding is preserved in dated records. Current
handoff documents distinguish it from the newly observed local export; the
presence of an export does not prove completed historical training or metrics.

The publication excludes the full dataset and external model files. Fresh-clone
demos need only the two included aerial examples or the built-in synthetic source.
